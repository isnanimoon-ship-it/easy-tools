# 여러 이미지로 애니메이션 GIF 생성기 SPEC

## 목표

JPG, PNG, WebP 정지 이미지 여러 장을 브라우저에서 순서대로 합쳐 애니메이션 GIF로 저장한다. 입력 파일은 서버로 전송하지 않는다.

## V1 범위

- URL: `/{locale}/tools/animated-gif-maker`
- 2~20개 정지 이미지 업로드 및 추가
- 프레임 순서 변경과 프레임별 표시 시간(20~10,000ms)
- 출력 크기(최대 1600×1600), 전체 표시/가득 채우기, 배경색
- 프레임당 색상 수 64/128/256
- 무한 반복 또는 1회 재생
- 결과 미리보기와 GIF 다운로드
- 한국어, 영어, 일본어 및 기존 light/dark 테마 지원

## 제한 및 안전장치

- 파일당 15 MiB, 이미지당 24MP, 입력 합계 80MP
- 출력 픽셀×프레임 합계 40MP
- 기존 애니메이션 GIF/WebP 프레임 추출 미지원
- 투명 GIF 출력 미지원. 투명 영역은 배경색으로 합성
- GIF의 256색 제한 및 사진/그러데이션 품질 저하 안내
- 메타데이터 보존 미지원

## 완료 조건

- 업로드, 순서 변경, 개별 지연, 맞춤 방식, 반복 설정이 결과에 반영된다.
- 정상적인 GIF 시그니처와 2개 이상의 프레임을 가진 결과가 생성된다.
- 초기화·삭제 시 Object URL과 ImageBitmap을 정리한다.
- 모바일 320px 이상에서 가로 스크롤 없이 사용할 수 있다.
- lint, type-check, test, production build를 통과한다.
